🔄 Team Git Workflow

Each member works on their assigned feature branch.

1. Get the latest project

git pull origin main

2. Switch to your feature branch

git checkout feature/your-branch

3. Add your changes

git add .

4. Commit your changes

git commit -m "Add feature"

5. Push the branch

git push -u origin feature/your-branch

6. Create a Pull Request

After pushing, create a Pull Request on GitHub from your feature branch
into main.

✅ Contribution Rules

Work only on your assigned feature branch.

Do not directly modify another member's feature.

Keep HTML, CSS, and JavaScript organized.

Use clear and meaningful commit messages.

Test the feature before creating a Pull Request.

Pull the latest changes before starting new work.

Merge features into main only after review.

🚀 Running the Project

Clone the repository.

Open the project folder in VS Code.

Open index.html.

Use Live Server or another local development server.

Test all integrated features.
